## 🌟 Overview

**Hex Softwares Book Library** is a front-end project that helps users **add, view, edit, and delete** books from their personal collection.  
It’s lightweight, fully responsive, and built purely with HTML, CSS, and JavaScript — no frameworks, just pure web magic.  

🧠 Ideal for learning CRUD logic, LocalStorage handling, and DOM manipulation.

---

## 🚀 Features

- 📘 Add books with details (Title, Author, Genre)  
- 🧾 Edit or delete entries dynamically  
- 🔍 Search and filter your library  
- 💾 Data saved with **LocalStorage** (persistent after reload)  
- 📱 Responsive design for all devices  
- ⚡ Fast and minimal — zero dependencies

Books display instantly using DOM manipulation

Data is saved automatically in LocalStorage

Delete or update existing entries with one click
